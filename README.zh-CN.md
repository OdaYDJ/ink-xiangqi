# 墨弈 · Ink Chess

**墨弈**是一款在水墨画中对弈的中国象棋游戏。棋盘是一张浮在碧水上的宣纸：水底光影流转，页边枝叶轻摇，雨滴在水面荡开涟漪，琵琶声若有若无。每一步棋都以墨回应——落子时笔锋随棋子掠过，墨色在纸上缓缓晕开；将帅被将军时，一抹朱砂随之浮现。

规则仍是传统象棋；不同的是开局——每一局都可以得到一个**新的布局**。棋子的职能与所在行列不变，车马象炮乃至将帅却换了位置，每一局都需要重新观局、重新思量。

> 熟悉的棋盘，熟悉的棋子，陌生的布局。

**开始对弈：** https://odaydj.github.io/ink-xiangqi/ ——在浏览器中打开即可，电脑、平板、手机均可，无需安装。

## 玩法

1. **选择对手**：初學、棋手或國手三档难度；或选 雙人對弈，与朋友在同一台设备上对局。
2. **选择开局**：奇局 为随机发出的新布局，古局 为传统布局。
3. **执红先行**：点选棋子即可看到可走的位置，再点目标位置落子。全程遵循标准象棋规则，包括将帅不得照面、蹩马腿、塞象眼等。
4. **对局中**：悔棋 撤回上一步，重來 以同一布局重新开始，易墨 换一个新布局。棋谱记于棋盘一侧，中文版用中文记谱（炮二平五），英文版用 WXF 记谱（C2.5）。

对局以将死结束；一方无子可走即判负（困毙）；长期重复或久无进展则判和。

## 以墨色命名的布局

每一个随机布局都以一种墨色命名：焦墨、濃墨、重墨、淡墨、清墨五色，以及松煙、潑墨等墨名。同一墨色永远对应同一局面，中英文版本相同（焦墨 = *Scorched Ink*）。

- 在首页，墨色 留空即随机取墨；点一下右侧的洗牌记号可抽取一种墨色；也可以直接输入墨名。
- 想与朋友下同一盘棋，只需告诉对方墨名，或发送链接，例如 `https://odaydj.github.io/ink-xiangqi/?seed=焦墨`。

随机布局在开局时总是公平的：双方都不会一开局就被将军，将帅不会照面，任何一方也无法在第一步就得子得利。
